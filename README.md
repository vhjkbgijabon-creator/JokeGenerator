# Joke Generator 😂

A fun and simple joke generator application that fetches random jokes from an external API.

## ✨ Features:

- 🎲 **Random Jokes** - Get a new joke every time
- 📋 **Copy to Clipboard** - Easy sharing
- 📤 **Share** - Share jokes with friends
- 🎨 **Beautiful UI** - Modern and sleek design
- ⚡ **Fast** - Instant joke loading
- 📱 **User Friendly** - Simple and intuitive

## 🚀 Usage:

### Method 1: Run Python directly
```bash
pip install -r requirements.txt
python joke_generator.py
```

### Method 2: Download EXE (Recommended)
1. Download the ZIP file from GitHub
2. Extract it
3. Double-click `build.bat`
4. Wait for `Joke Generator.exe` to be created
5. Open `dist/Joke Generator.exe` and enjoy!

## 📋 Requirements:

- Python 3.7+ (for running from source)
- requests library
- pyperclip library

## 🔑 API Used:

- [Official Joke API](https://official-joke-api.appspot.com/)
- Free and no authentication required
